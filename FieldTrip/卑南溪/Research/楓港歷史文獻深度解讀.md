# 📜 楓港歷史文獻深度解讀 (Historical Research: Fenggang)

此檔案整理了自《臺灣通史》等核心史料中關於「楓港」（古稱風港）的關鍵記載，旨在為「南迴跨域探訪」提供深厚的歷史座標。

---

## 1. 空間座標：歷史上的「南路」節點
根據《臺灣通史·郵傳志》記載，楓港是清代連結鳳山縣（高雄）與卑南（台東）最重要的交通中繼站。

### **道里表對照整合 (Distance Table)**
*   **前山段**：恆春 → 柴城 (15里) → 柴寮 (18里) → **楓港** (15里) → 枋山 (15里)。
*   **後山段 (南路)**：從楓港轉入山區，行經以下節點抵達卑南：
    - `楓港 → 射不力 (10里) → 雙溪口 (15里) → 大雲頂 (20里) ... → 阿郎壹溪 → 卑南`。
    - **總里程**：236 里（自楓港至卑南）。

## 2. 生態系系系系系系系系系系系系系系系系系系系系特徵：烏魚排卵的南方分界線
《臺灣通史·虞衡志》記載了楓港在生物地理學上的獨特意義。

*   **信魚的軌跡**：烏魚（鯔魚）每年冬至前自北方南下，風味最美。
*   **楓港的地位**：史載烏魚向南游至「恆春之**楓港**」時開始「生卵」。
*   **回頭烏**：產完卵後魚體消瘦、味劣，稱為「回頭烏」，隨即北返。這使得楓港成為觀察此自然節令循環的重要地理標界。

## 3. 軍事與開拓史：莊民的主體性
楓港在歷史衝突中展現了極強的在地行動力。

### **乾隆平亂 (1788)**
*   林爽文事件中，叛軍領袖莊大田南逃至此。
*   統帥福康安率滿漢兵追擊至**風港**（楓港），「越菁穿林，深入三十里」，展現了楓港山區地形的艱險與軍事戰略價值。

### **射不力社事件 (1892)**
*   **導火線**：光緒十八年六月，活動於楓港後山（今獅子鄉山區）的排灣族「射不力社 (Sapulid)」與楓港莊民發生血親報復衝突。
*   **深夜突襲**：射不力社集結周邊部落千餘人夜襲楓港。莊民併力拒戰，向恆春縣署求援。
*   **軍事反擊**：清廷派總兵**萬國本**率兵千餘討伐。因山區地形艱險，萬國本**「募楓港莊民六十人為導」**，由在地壯觀擔任嚮導深入敵營。
*   **汪斌突襲**：汛官汪斌率壯士突入部落，擒斬土目，破老佛、巴士墨二社。
*   **事件終局**：後因八月大雨山洪暴發，軍隊撤回。新任知縣陳文煒調停議和，但地方民番仇殺仍持續。
