# 蘭陽溪流域探索現場備忘錄 (2026-05-15)

本檔案整合了蘭陽溪流域的歷史背景考掘與 2026 年 5 月現場探索的關鍵脈絡，作為《河流探索》方法論的實踐資產。

## 📜 歷史背景 (Deep-Time Context)

根據《臺灣通史》與歷史資料庫檢索，蘭陽溪流域具備以下核心地層：

1. **官佃體制與社會結構**：
   - 蘭陽平原採取獨特的「無業戶、以民為官佃」模式，減少了大地主的壟斷。這使得早期的開墾與水利設施（如水粟）與基層農民的生活緊密對照整合。
2. **治水即治生**：
   - 舊稱「宜蘭濁水溪」，歷史上頻繁出現「沖崩塌壞」。治理河流不只是防災，更是維護整個官佃經濟系統穩定的核心手段。
3. **族群與權力邊界**：
   - 「噶瑪蘭」意指平原的人。歷史上的開墾過程（如吳沙入墾）伴隨著與高山泰雅族權力邊界的動態推移。

## 🗺️ 探索行程與點位 (Itinerary)

### Day 1：垂直地景與權力網路
- **路徑**：武暖石板橋 (礁溪) → 治水工事竣功記念碑 → 阿蘭城集水井 → 思源埡口 → 南山村 → 馬諾源 → 牛鬥橋。
- **觀察重點**：
  - **監控地誌學**：驗證日治駐在所對部落原始社址的視線控制。
  - **消失的聚落**：馬諾源從「生活空間」轉化為「生產空間」的地景演變。

### Day 2：地質適應與治理邊界
- **路徑**：天送埤車站 → 蘭陽溪西瓜田 → 深溝水源生態系系系系系系系系系系系系系系系系系系系系系系系系系園區 (員山取水口) → 五結防潮閘門 → 蘭陽溪口。
- **觀察重點**：
  - **伏流美學**：觀察蘭陽溪沖積扇「扇頂入滲、扇端湧出」的物理特徵。
  - **地質決定論**：板岩沖積扇如何形塑西瓜產業與工業電力。
