## 📖 專案簡介

《流域導航》是一部結合 **地貌學、地名政治、技術政治學** 與 **生成式 AI (GenAI)** 技術的實驗性地誌作品。我們試圖撥開水泥堤防與官方敘事的迷霧，帶領讀者看見台灣流域背後的靈魂座標。

本專案的核心在於提出一套「人、河、AI 三位一體」的探索典範。除了精闢的流域解析，更提供了一套可實踐的工作流，賦予現代探索者「數位導航」與「地景解讀」的能力。

## 🌟 核心特色

- **深度解讀模型**：不談網美景點，專注於「地學宿命」、「權力架構」與「文化復振」的深度批判。
- **[v2.1] 跨時空模型化 (Deep-Time Modeling)**：引入考古遺跡作為「絕對座標」，透過 **OO-History (物件導向歷史)** 模擬先民生存劇本。
- **二階段研究注入**：內容結合了橫向跨域資料與針對特定流域的深度採掘（Deep Research），具備極高的資訊厚度。
- **數位孿生導航**：連結 `taiwan-history-atlas` 智庫，實踐 Layer 0-4 的全方位空間對照整合。
- **WalkGIS 數位神經系統**：整合 [WalkGIS](https://walkgis-544663807110.us-west1.run.app/) 工具，推動「公民參與、集體共創、疊代豐富」的自生長圖資。

## 🚀 v2.1 重大更新：遺跡與生存演義

本版本正式引入了 **「超越文獻的硬證據」** 教學，幫助探索者在缺乏文字記載的史前時空中進行邏輯復原：
- **OO-History 模型化**：採用 Root-Spec-Entity 三層繼承架構，系統化處理全台 2,500+ 處遺址資料。
- **生存第一原理 (L3)**：透過「能源平衡模型」與「遷徙演演演演演演演演演演演演演演演演演演演演演算法」，重建先民與河流博弈的生活樣態。
- **空間拓樸驗證 (L4)**：利用離河距離 (HRD) 與高程位能模型，量化驗證地景假說。

## 🗺️ 內容目錄 (TOC)

1.  **第一部分：探索基本功** —— 閱讀河流的方法論 (加入考古導航與 OO-History 邏輯)。
2.  **第二部分：流域導航索引** —— 台灣 11 門靈魂流域的深度解讀 (南科案例實戰)。
3.  **第三部分：動態實境錄檔案櫃** —— 導航者的實地探訪與批判思考紀錄。
4.  **第四部分：未來導航** —— 當 Rivers 遇見 AI (模型化迴圈：預測 -> 驗證 -> 修正)。

## 🛠️ 數位工具箱 (Appendix)

本專案提供豐富的自動化指令與腳本：
