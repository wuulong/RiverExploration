# 《流域導航》v2.1 升級提案：從 HGIS 對照整合邁向「跨時空模型化與遺蹟導航」

## 1. 核心願景
延續 v2.0 的 Layer 0-1-2 基礎，v2.1 的目標是引入 **「超越文獻」** 的探索維度。透過 **考古遺蹟 (Relics)** 的硬證據，結合 **物件導向歷史 (OO-History)** 的模型化思維與 **系統工程 (System Engineering)** 的模擬框架，落實「方法論先行」的寫作策劃。本書將引導探索者從「現狀描述」提升到「跨時空邏輯模擬」，建立 **「模型預測 -> 實地檢證 -> 修正補充」** 的動態導航系統。

---

## 2. 補完架構：從 Layer 2 邁向 Layer 4

在 v2.1 中，我們將明確定義 Layer 3 的推論與演繹功能，並將其視為建構「建築基本樣態」的核心：

### 2.1 Layer 3：屬性推論與關聯演繹 (Scenario & Attribute Deduction)
- **定義**：在知識模型（L2）之上，進行 **「分析與假設遺跡/物件屬性」**。建立物件間的互動邏輯與場景劇本。
- **引入模擬概念 (from T260308-HHH04)**：
    - **能源平衡模型**：將史前聚落視為追求飢餓度平衡、資源獲取最大化的動態單元。
    - **決策邏輯演繹**：分析環境模型（資源格網、氣候週期）與遷徙演演演演演演演演演演演演演演演演演演演演演演演演演演算法（能耗比、族群記憶）的關聯。
- **應用**：模擬「若是河道改道」會如何觸發遷徙決策，進而產出遺址分佈的預測劇本。

### 2.2 Layer 4：空間拓樸與生存代數 (Spatial Topology)
- **定義**：利用量化資料（如離河距離 HRD、聚類分析）作為 **「驗證與修正」** Layer 3 假設的物理證據。
- **資料排名策略 (Ranking)**：定義國家級、專項級與文化斷點級的遺跡權重，最佳化分析負擔。

### 3. 三大核心發想模組：立論與預測

#### A. 遺蹟作為「絕對座標」與生存邏輯
- **核心思維**：遺址是土地上最誠實的物理證據。導航不應只是「找點」，而是要從遺址座標中展開 **「生存決策」** 的模型化。
- **方法論**：新增「遺跡 ID 勾稽體系」(Relic-ID/Artifact-ID)，結合 Markdown Sidecars 實現考證邏輯的動態掛載與編輯。
- **資料架構 (taiwan-history-atlas)**：導入 `relic_master` 資料結構，包含時代層位 (Era)、信心水準 (Confidence)、與 AI 專用 JSON 欄位 (`for_ai`)，實現結構化與非結構化知識的共生。

#### B. 物件導向歷史 (OO-History) 的樣態建構
- **核心思維**：流域不只是文本，而是具備「繼承」與「覆寫」性質的物件系統（如：文化層的堆疊即是屬性的覆寫）。
- **方法論**：建立 **「地景物件類別架構 (Class Arch)」**。預先定義如「長濱文化-洞穴居住」或「大坌坑文化-早期農業」的基礎屬性樣態。

#### C. 直覺模擬與地景復原 (Generative Landscape Simulation)
- **核心思維**：工具未動，思想先行。透過 AI 的推論能力，在立論階段即針對特定流域展開 **「基本樣態」** 的發想。
- **方法論**：推動「模型預測（L3 演繹）」與「實地檢證（M:: 捕捉）」的完整迴路。展示如何利用「遷徙演演演演演演演演演演演演演演演演演演演演演演演演演演算法」與「資源週期」預測出史前地景，再引導讀者到現場進行修正。
- **技術自動化**：實現從 SQLite 資料庫直接產出 QGIS 專案檔 (`.qgs`)，透過 `qgis-project-architect` Skill 自動化渲染空間權重與熱點分析，縮短資料到視覺化的距離。

### 5. 戰略藍圖：模型驅動的探索 (Model-Driven Exploration)
本版本強調「建築（演繹模型）」必須在立論時先立起來。探索不再是盲目的收集，而是帶著 **「發想與展開」** 後的基礎樣態（包含族群記憶、資源成本等參數），去土地上尋找對應的證據。這套架構將使《流域導航》成為一套具備高度適應性與演化能力的動態智庫。
